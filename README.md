# Резюме Фёдора Ларина

Статический сайт с двумя версиями резюме:

- коммерческое резюме Python Backend Developer — главная страница;
- профиль преподавателя и ментора — `/tutor/`.

Сайт не требует сборки: GitHub Actions публикует HTML, CSS и изображения напрямую в GitHub Pages.

## Локальный просмотр

```powershell
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.
